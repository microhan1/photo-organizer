## 사진 정리 v0.1.0

첫 버전입니다. 폰·카메라·카카오톡에서 쏟아진 사진과 동영상을 촬영 날짜별 폴더(`2024/2024-03-15/`)로 정리하고, 아이폰 HEIC를 JPG로 바꾸고, 같은 사진을 걸러냅니다. 인터넷 없이 동작하고, 사진은 어디에도 올라가지 않고, 실행한 것은 되돌릴 수 있습니다.

### 되는 것

- **날짜 판별**: EXIF → 동영상 정보 → 파일명(카카오톡·삼성·구글·왓츠앱·스크린샷·밴드·라인·일반) → 짝 파일 → 수정 시각(옵션) 순. 표의 "근거" 칸에 어디서 읽었는지 보입니다. 카메라 시계가 초기화된 날짜는 "의심"으로 표시합니다.
- **HEIC → JPG**: 촬영일·GPS·카메라 정보와 색 프로파일을 그대로 옮기고, 눕는 문제를 막으려고 사진을 실제로 돌려 저장합니다. "정리 안 함 — HEIC 변환만"으로 폴더는 그대로 두고 변환만 할 수도 있습니다. 라이브 포토의 `.mov`는 변환하지 않고 사진과 함께 움직입니다.
- **중복 찾기**: 완전히 같은 파일은 `_중복` 폴더로(삭제하지 않음). 비슷한 사진(회전 포함)은 옵션이며 그룹만 보여 주고 남길 것은 사람이 고릅니다. 카카오톡 압축본 등은 "중복 추천"으로 표시합니다.
- **되돌리기**: 기록(`organize_log.json`)을 먼저 저장해야 옮기기 시작합니다. 저장할 수 없으면 아무것도 옮기지 않고, 되돌리기는 옮긴 파일·변환으로 만든 JPG·지운 빈 폴더를 모두 돌려놓습니다. 다시 실행하면 전부 "변경 없음"입니다.
- 한국어·영어·중국어·일본어 화면, 밝은/어두운 테마, 명령줄(`--dry-run`, `--undo` 등), 260자가 넘는 경로, 원드라이브·아이클라우드 "클라우드 전용" 파일은 열지 않고 건너뜀.

### 확인한 것과 못 한 것

- 자동 시험 188개(파이썬 3.12·3.14), 규칙을 하나씩 깨뜨려 보는 시험 17개가 모두 잡혔습니다. 10만 장 폴더를 처음 열 때 스캔·계획 약 61초, 최대 메모리 약 415 MB.
- 실제 사진 폴더의 사본으로 정리 → 다시 실행(이동 0) → 되돌리기 후 파일 해시가 똑같음을 확인했습니다.
- **직접 확인하지 못한 것**: 변환한 JPG를 Windows 사진 앱·크롬·카카오톡에서 여는 것, 실제 원드라이브 폴더에서 다운로드가 시작되지 않는 것(파일 속성으로만 시험함). 문제가 보이면 알려 주세요.

**Photo Organizer v0.1.0** — first release. Sorts photos and videos into date folders (`2024/2024-03-15/`), converts iPhone HEIC to JPG (EXIF, GPS and colour profile kept, picture turned upright), and sets duplicates aside. Dates come from EXIF, video metadata, KakaoTalk/Samsung/Pixel/WhatsApp/screenshot file names, paired files, or the modified time (optional), and the table shows which. Works offline, uploads nothing, and every run can be undone: the log is saved before the first file moves. UI in Korean, English, Chinese and Japanese. Not checked by hand: opening the converted JPGs in Windows Photos, Chrome and KakaoTalk, and a real OneDrive online-only folder.
