## 사진 정리 v0.1.6

**의견 보내기** 버튼을 다듬은 작은 버전입니다. 정리·변환·중복·되돌리기·새 버전 확인은 v0.1.5와 같습니다.

### 바뀐 것

- **키보드로도 누를 수 있습니다.** Tab으로 **의견 보내기**에 초점을 옮기고 Enter나 Space를 누르면 열립니다. 초점이 오면 버튼에 테두리가 보입니다(버튼 크기는 그대로). 창 위쪽의 Tab 순서도 보이는 순서대로(의견 보내기 → 언어 → ⚙) 바꿨습니다.
- **마우스를 올리면 짧은 설명이 뜹니다.** 「안 되는 것·불편한 것·바라는 기능을 알려 주세요(브라우저가 열립니다)」. 창이 작거나 화면 끝에 있어도 설명이 잘리지 않고, 언어를 바꾸면 설명도 바뀝니다.
- **열리는 페이지 언어를 시리즈 규칙에 맞췄습니다.** 화면 언어가 한국어면 한국어 페이지, 그 밖의 언어는 모두 영어 판 페이지가 열립니다. **업데이트** 알림의 페이지도 같은 규칙입니다.
- 일본어·중국어 README의 책갈피 라이브러리 링크가 영어 판 툴 페이지로 갑니다.

### 확인한 것

- 전체 시험(파이썬 3.12·3.14), 화면 시험 3회 연속 통과. 새 시험은 Tab 순서, Enter·Space를 누를 때마다 브라우저 한 번, 다른 키는 무반응, 초점 테두리와 크기, 설명이 뜨고 사라지는 때, 4개 언어 설명 문구, 최소 크기 창을 화면 왼쪽·오른쪽 끝에 두었을 때 설명이 창·화면 안에 있는지, 언어 코드별 페이지(한국어·영어·일본어·중국어·그 밖·빈 값), README 링크를 봅니다. 시험은 실제 브라우저를 열지 않고 네트워크 연결 시도 0건입니다.
- 빌드한 exe를 죽은 프록시 환경으로 띄워 창이 정상으로 뜨고 닫히는 것을 확인했습니다(버튼은 누르지 않음).

v0.1.5 이하로 정리한 폴더는 그대로 쓸 수 있고 되돌리기도 됩니다. 의견은 [책갈피 툴 페이지의 의견 칸](https://chaekgalpi.co.kr/tools/photoorganizer#feedback)이나 [GitHub Issues](https://github.com/microhan1/photo-organizer/issues)로 보내 주세요.

### 다운로드

`photo-organizer.exe`를 받아 더블클릭합니다. 설치가 필요 없습니다. 서명되지 않은 exe라 SmartScreen 경고가 뜨면 "추가 정보 → 실행".

**Photo Organizer v0.1.6** — polishes the **Send feedback** button. It can now be reached with Tab and opened with Enter or Space, with a visible focus frame (same size); the header's Tab order now follows what you see (Send feedback → language → ⚙). Resting the mouse on it shows a short note, "Tell us what's broken or missing (opens your browser)", which stays inside the window and the screen and follows a language switch. The page it opens follows the series rule: Korean screens get the Korean page, every other language the English page, and the **Update** notice uses the same rule. The Japanese and Chinese READMEs now link to the English tools page. Sorting, conversion, duplicates, undo and the update check are unchanged from v0.1.5. Checked: full test suite on Python 3.12 and 3.14, GUI tests 3 times in a row, no real browser and no network connection attempt in any test; the built exe started behind a dead proxy and opened and closed its window normally. Feedback: the [feedback box on the tool's page](https://chaekgalpi.co.kr/en/tools/photoorganizer#feedback) or [GitHub Issues](https://github.com/microhan1/photo-organizer/issues).
