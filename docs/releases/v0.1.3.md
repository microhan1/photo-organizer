## 사진 정리 v0.1.3

「새 버전 확인」을 넣은 버전입니다. 정리·변환·중복·되돌리기 기능은 v0.1.2와 같습니다.

### 새로 넣은 것

- **새 버전 확인.** 프로그램을 켜면 1.5초 뒤 백그라운드에서 책갈피 서버(chaekgalpi.co.kr)에 새 버전이 있는지 한 번 묻습니다. 보내는 것은 **도구 이름(`photoorganizer`)·버전·OS 계열(`win`)뿐**이고, 파일·사진·경로·기기 정보는 보내지 않습니다. 하루 한 번만 확인하고, 연결이 안 되거나 서버가 답하지 않으면 아무것도 표시하지 않습니다(그날은 다시 시도).
- 새 버전이 있을 때만 창 아래에 한 줄 알림이 나옵니다: 「새 버전이 나왔습니다: {최신} (현재 {버전})」 · **업데이트**(책갈피 툴 페이지가 열림) · **다음에**(그 버전은 다시 알리지 않음, 더 새 버전은 알림). 팝업 창을 띄우지 않고, 자동으로 내려받거나 바꾸지 않습니다.
- 설정 ⚙ → 일반 탭의 **새 버전 확인** 체크(기본 켬)로 끌 수 있습니다. 끄면 서버에 묻지 않습니다.
- README의 "인터넷 없이 동작" 약속에 이 예외를 적었습니다: 인터넷 없이 동작합니다 — 새 버전 확인만 예외(도구 이름·버전만, 하루 한 번, 설정에서 끔).

### 확인한 것

- 단위 시험 24개(가짜 응답): 같은 날 두 번 켜도 한 번만 물음, 끄면 0회, 오프라인이면 날짜를 쓰지 않음, 실패는 조용히(오프라인·타임아웃·HTTP 500·잘못된 JSON), `updateAvailable`이 false·null·문자열·숫자면 알림 없음, true면 한 번, 「다음에」 뒤 같은 버전은 다시 안 알림, 다른 도메인 url은 열지 않음, 보내는 헤더에 도구 이름·버전 외 아무것도 없음.
- 작업 스레드는 Tk 객체를 쥐지 않습니다(결과를 상자에 두고 창 쪽이 0.1초마다 가져감). 서버 응답을 기다리는 동안 창을 닫아도 죽지 않는 것을 3회 반복 시험으로 확인했습니다.
- 화면 시험 9개: 알림 줄이 한 줄로 결과 띠 위에 들어가고 실행·되돌리기 버튼과 옵션 줄 위치가 그대로, 4개 언어 최소 창 크기에서도 잘리지 않음, 언어를 바꿔도 알림이 새 언어로 남음.
- 전체 시험(파이썬 3.12·3.14), 화면 시험 3회 연속, 규칙을 하나씩 깨뜨려 보는 시험(알림 조건·열 수 있는 주소) 모두 잡힘.
- 빌드한 exe를 임시 폴더에서 실제로 켜서 서버에 묻고 `update_check_last`가 기록되는 것을 확인했습니다.
- **직접 확인하지 못한 것(이전과 같음)**: 변환한 JPG를 Windows 사진 앱·크롬·카카오톡에서 여는 것, 실제 원드라이브 폴더에서 다운로드가 시작되지 않는 것.

v0.1.2 이하로 정리한 폴더는 그대로 쓸 수 있고 되돌리기도 됩니다.

**Photo Organizer v0.1.3** — adds an update check; sorting, conversion, duplicates and undo are unchanged from v0.1.2. 1.5 s after the window opens, once a day, the app asks the Chaekgalpi tools server (chaekgalpi.co.kr) whether a newer version exists, sending only the tool name (`photoorganizer`), its version and the OS family (`win`) — no file, photo, path or device information. When a newer version exists, a one-line notice at the bottom offers **Update** (opens the tool's page on the site) and **Later** (that version is not mentioned again); nothing is downloaded or replaced automatically, and there is no pop-up. Settings ⚙ → General → **Check for updates** turns it off. The README's "works offline" promise now names this one exception. Still not checked by hand: opening converted JPGs in Windows Photos, Chrome and KakaoTalk, and a real OneDrive online-only folder.
