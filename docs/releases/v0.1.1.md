## 사진 정리 v0.1.1

"다시 실행해도 조용해야 한다"를 무작위로 만든 어지러운 폴더 1,600개로 점검해서 찾은 결함을 고친 버전입니다. 화면과 기능은 v0.1.0과 같고, 평소에 쓰는 방식(폴더 하나를 정리하고 끝)에서는 달라지는 것이 거의 없습니다. 아래는 **정리한 뒤 같은 폴더를 다시 실행하거나, 옵션을 조합해 쓸 때** 생기던 문제입니다.

### 고친 것

- **복사 모드로 같은 정리를 다시 실행하면 사본이 `_중복`에 쌓이던 문제.** 대상에 이미 같은 내용의 사본이 있으면 이제 "변경 없음"입니다. 새로 늘어난 사진만 복사합니다.
- **폴더 연결(junction·심볼릭 링크)이 위 폴더로 되돌아가면 같은 사진을 계속 읽던 문제.** 연결 폴더는 들어가지 않습니다(실제 폴더를 직접 고르세요).
- **"정렬용 이름 바꾸기"를 `{source}` 폴더 규칙과 같이 쓰면 다시 실행할 때마다 폴더가 바뀌던 문제.** 이름 앞에 붙은 날짜 접두어 때문에 카카오톡·스크린샷 등 출처를 못 알아봤습니다. 날짜를 직접 고쳐도 접두어가 쌓이지 않습니다.
- **언어를 바꾸고 다시 실행하면 `날짜 없음` 폴더의 파일이 새 이름의 폴더로 옮겨지던 문제.**
- **"HEIC·RAW 짝의 JPG를 중복으로"와 "HEIC → JPG"를 같이 켜면 다시 실행할 때마다 변환이 또 나오던 문제.** 두 옵션은 서로 모순이라 이제 JPG를 중복으로 보는 옵션이 켜져 있으면 변환이 꺼지고(체크박스가 흐려지고 설정 문구에 표시), 곧 `_중복`으로 갈 JPG의 날짜는 짝의 날짜를 정하는 근거에서 뺍니다.
- **폴더 규칙에 `{ext}`를 쓰고 변환하며 원본 HEIC를 옮기면, 남은 JPG가 다시 실행할 때 다른 폴더로 옮겨지던 문제.**

### 확인한 것

- 무작위 시나리오 1,600개(정리 위치 4곳 × 무작위 옵션·언어): 어떤 파일의 내용도 사라지지 않음, 새 경로가 겹치지 않음, 다시 실행하면 할 일 0, 되돌리면 처음과 똑같음 — 모두 통과. 손으로 설계한 시나리오 60개와 GUI 시나리오(드래그한 경로, 실행 중 옵션 조작, 설정 창 잘림 등)도 통과. 규칙을 하나씩 깨뜨려 보는 시험 24개가 모두 잡혔습니다.
- 실제 사진 폴더의 사본으로 정리 → 다시 실행(이동 0) → 되돌리기 후 파일 해시가 똑같음을 확인했습니다. 10만 장 폴더를 처음 열 때 스캔·계획 약 65초, 최대 메모리 약 416 MB.
- 한 번 보인 뒤 재현되지 않은 것: 되돌리기 끝에서 기록 파일 저장이 실패한 적이 한 번 있었습니다(원인 모름). 이때는 파일은 되돌려지고 화면에 경고가 나옵니다.
- **직접 확인하지 못한 것(v0.1.0과 같음)**: 변환한 JPG를 Windows 사진 앱·크롬·카카오톡에서 여는 것, 실제 원드라이브 폴더에서 다운로드가 시작되지 않는 것.

v0.1.0으로 이미 정리한 폴더는 그대로 쓸 수 있습니다. 기록 형식은 같고, 되돌리기도 됩니다.
