## 사진 정리 v0.1.5

**의견 보내기** 버튼을 더한 작은 버전입니다. 정리·변환·중복·되돌리기·새 버전 확인은 v0.1.4와 같습니다.

### 바뀐 것

- **의견 보내기.** 창 위쪽 언어 선택 옆에 **의견 보내기** 버튼이 생겼습니다. 누르면 브라우저로 책갈피 툴 페이지의 의견 칸이 열리고, 로그인 없이 안 되는 것·불편한 것·바라는 기능을 적어 보낼 수 있습니다. 화면 언어가 한국어가 아니면(English·简体中文·日本語) 영어 판 페이지가 열립니다.
- 프로그램이 직접 보내는 것은 없습니다. 주소에 붙는 것은 프로그램 버전과 "프로그램에서 열었다"는 표시뿐입니다(파일·사진·경로·기기 정보 없음).
- 브라우저가 열리지 않으면 주소를 보여 주는 작은 창이 뜹니다. **주소 복사**를 눌러 브라우저에 붙여 넣으면 됩니다.
- README 4개 언어에 「의견 보내기」 절을 더했습니다. GitHub Issues도 그대로 받습니다.

### 확인한 것

- 전체 시험(파이썬 3.12·3.14 각 452개 통과, 2개 건너뜀 — 새 시험 84개), 화면 시험 3회 연속 통과. 새 시험은 주소(4개 언어·대소문자·모르는 언어), 버전(빈 값·`+`·공백·`&`·`#`·한글), 버튼 한 번에 브라우저 한 번, 실행 중 언어 바꾸기, 브라우저 실패 세 가지(거짓·브라우저 오류·OS 오류)에서 창이 그대로인지, 4개 언어 문구를 봅니다. 시험은 실제 브라우저를 열지 않고 네트워크 요청 0건입니다.
- 빌드한 exe를 죽은 프록시 환경으로 띄워 창이 정상으로 뜨고 닫히는 것을 확인했습니다(버튼은 누르지 않음).
- **직접 확인하지 못한 것(이전과 같음)**: 변환한 JPG를 Windows 사진 앱·크롬·카카오톡에서 여는 것, 실제 원드라이브 폴더에서 다운로드가 시작되지 않는 것.

v0.1.4 이하로 정리한 폴더는 그대로 쓸 수 있고 되돌리기도 됩니다.
