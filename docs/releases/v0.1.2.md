## 사진 정리 v0.1.2

결함 하나를 고친 작은 버전입니다. 화면과 기능은 v0.1.1과 같습니다.

### 고친 것

- **이름이 아주 긴(약 150자 이상) 사진 여러 장이 같은 날짜 폴더에서 이름이 겹치면, 다시 실행할 때마다 한 장이 ` (4)`, ` (5)`… 로 또 옮겨지던 문제.** 긴 이름은 경로 길이 제한에 맞춰 잘리는데, 잘린 뒤 같은 이름이 된 파일들의 번호를 이어 세는 과정에서 번호 없는 파일의 자기 자리를 건너뛰었습니다. 이제 이미 제자리에 있는 파일은 번호 계산과 상관없이 그대로 둡니다. 보통 길이의 이름에서는 생기지 않던 문제입니다.
- 폴더 연결(junction·심볼릭 링크)이 위쪽 폴더를 가리키는 경우를 공용 폴더 걷기에서도 들어가지 않게 했습니다(이 프로그램의 스캔은 v0.1.1부터 이미 막혀 있어 동작 변화는 없습니다).

### 확인한 것

- 새 시험: 줄기 60·150·200·240자의 겹치는 이름, 경로 제한에 거의 닿는 깊은 대상 폴더, 이름 바꾸기 옵션과 HEIC 변환을 함께, 같은 긴 이름 5,000개. 모두 정리 → 다시 실행(할 일 0) → 되돌리기(처음과 동일).
- 전체 시험 306개(파이썬 3.12·3.14), 화면 시험 3회 연속, 규칙을 하나씩 깨뜨려 보는 시험 25개 모두 잡힘.
- **직접 확인하지 못한 것(이전과 같음)**: 변환한 JPG를 Windows 사진 앱·크롬·카카오톡에서 여는 것, 실제 원드라이브 폴더에서 다운로드가 시작되지 않는 것.

v0.1.1 이하로 정리한 폴더는 그대로 쓸 수 있고 되돌리기도 됩니다. 기록 형식은 바뀌지 않았습니다.
