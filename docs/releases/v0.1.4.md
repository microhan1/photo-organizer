## 사진 정리 v0.1.4

새 버전 알림의 링크와 시험 안전장치만 바꾼 작은 버전입니다. 정리·변환·중복·되돌리기 기능은 v0.1.3과 같습니다.

### 바뀐 것

- **영어 판 툴 페이지.** 새 버전 알림의 **업데이트**를 누르면, 화면 언어가 한국어가 아닐 때(English·简体中文·日本語) 책갈피 툴 페이지의 영어 판이 열립니다. 서버가 영어 판 주소를 주지 않으면 전과 같이 한국어 판이 열립니다. 서버로 보내는 것은 그대로입니다(도구 이름·버전·OS 계열 `win`뿐, 파일·사진·경로·기기 정보 없음). 알림이 한 줄로 나오고 자동으로 내려받거나 바꾸지 않는 것도 같습니다.
- README.en의 책갈피 링크를 영어 판 툴 페이지로 바꿨습니다.
- 개발용 시험이 운영 서버에 새 버전 확인을 보내지 않도록 막았습니다(프로그램 동작에는 영향이 없습니다).

### 확인한 것

- 전체 시험(파이썬 3.12·3.14 각 368개 통과, 2개 건너뜀), 화면 시험 53개 3회 연속 통과. 시험은 모두 운영 서버 요청 0건(막는 장치가 어긴 요청을 시험 실패로 잡습니다).
- 빌드한 exe를 임시 폴더에서 죽은 프록시 환경으로 띄워 14초 뒤에도 창이 정상으로 떠 있는 것을 확인했습니다. 서버에 닿지 않으면 그날을 기록하지 않는 것도 그대로입니다.
- **직접 확인하지 못한 것(이전과 같음)**: 변환한 JPG를 Windows 사진 앱·크롬·카카오톡에서 여는 것, 실제 원드라이브 폴더에서 다운로드가 시작되지 않는 것.

v0.1.3 이하로 정리한 폴더는 그대로 쓸 수 있고 되돌리기도 됩니다.
